# Continuous Wavelet Diagnostics (CWT)

Using continuous Complex Morlet wavelets, Sonon tracks scale-wise kurtosis and blade flutter modulation index.

## Diagnosed Failure Modes

- **Propeller Micro-Cracks**: Rotational subharmonics ($0.5\times, 1.5\times$ rotor fundamental).
- **Motor Bearing Spalls**: High-frequency spectral kurtosis exceedances ($\text{Kurtosis} > 4.5$).
- **Structural Resonance**: Airframe modal vibration peak shifts.
